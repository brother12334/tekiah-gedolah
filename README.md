# Teki'ah Gedolah

Single-product brand site for **Teki'ah Gedolah** tequila — a kosher-certified
Reposado Cristalino, 100% agave azul, produced in Tequila, Jalisco under the
El Poderío mark and imported by Helmsman Imports, Austin, TX.

The name is the last long blast of the shofar (תקיעה גדולה), which is also
where the tagline comes from: *it will blow you away.*

## Running it

It's a static site — no build step. Open `index.html`, or serve the folder:

```bash
npx serve -l 4321 .
```

## Layout

| File | What it is |
|---|---|
| `index.html` | The whole page |
| `styles.css` | All styling |
| `script.js` | Slider, carousel, search, age gate, reveals |
| `assets/` | Logo, favicon, retouched photography |
| `assets/README.md` | Image inventory, and **what's still placeholder** |

## Before this goes live

`assets/README.md` lists every invented detail still in the copy — the tasting
notes, the stockist list, the cocktails, the contact addresses. Read that file
first. The facts printed on the bottle itself (ABV, NOM, importer, kosher
certification) are accurate.
